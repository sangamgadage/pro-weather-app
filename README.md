# 🌤️ Pro Weather App

A modern, responsive weather dashboard built with HTML, CSS, JavaScript, and Chart.js.

## ✨ Features
* 🔍 **City Search:** Get real-time weather updates for any city.
* 🔊 **Voice Report:** Built-in Text-to-Speech support for instant weather reading.
* 📍 **GPS Location:** Fetch current weather using your device's location.
* 📈 **24-Hour Temp Graph:** Visual hourly temperature breakdown using Chart.js.
* 📅 **5-Day Forecast:** Daily weather predictions at a glance.
* 🌡️ **Unit Toggle:** Easily switch between °C and °F.
* 📱 **Fully Responsive:** Looks and works great on both mobile and desktop.

## 🛠️ Built With
* HTML5 / CSS3 / JavaScript (ES6+)
* Chart.js
* ResponsiveVoice / Web Speech API
* OpenWeatherMap API
